# Task Management System

A full-stack Task Management System built using:

## Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- MySQL

## Frontend
- React
- Axios
- Bootstrap

## Features
- User Authentication (JWT)
- Role-based Access (Admin, Student)
- Assignment Management
- Submission System
- Attendance Tracking
- Course Management

## How to Run Backend

cd backend-spring-boot
mvn spring-boot:run

## How to Run Frontend

cd frontend-react
npm install
npm start
